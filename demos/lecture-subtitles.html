University Lectures in English

A Korean university wanted its recorded courses in English. I built a system that does this automatically: it writes English subtitles and dubs each lecture in the professor's own voice. So far it has done 7 courses, more than 100 hours of video.

The problem

Technical words are where AI usually fails. If speech recognition has never heard a term like "flip-flop" or "Karnaugh map", it writes something else, and then the translation is wrong too.

How I solved it

  • Every lecture comes with slides, and the slides spell the technical words correctly. The system reads the slides, so it knows which words to expect.
  • Before translating, it builds a word list for the whole course, so each term is translated the same way every time.
  • Each subtitle gets a confidence score, so people only need to check the uncertain ones.
  • The voice is cloned from the professor's own lectures, and every finished video is checked automatically to make sure no line is missing.

Results

  • 7 courses, 100+ hours of lectures delivered in English.
  • 99.5% of course terms were right the first time: in a human review of one course's 585-term word list, only 3 needed fixing.
  • 100% of lines made it into the dub: in one 15-lecture course, all 8,969 lines were confirmed present.
